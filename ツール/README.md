# ツール

**成果物ではない。** 試験仕様書を生成するための作業用スクリプト。

## 試験仕様書を生成.py

`結合試験仕様書.xlsx` を生成する。項目の追加・修正は `試験項目.py` を編集してから実行する。

```
python3 ツール/試験仕様書を生成.py
```

`openpyxl` などの外部ライブラリは使えないため、**`totaltest.xlsx` の `styles.xml` と `theme1.xml` を
流用**し、シートの XML を組み立てて zip し直している。列幅・スタイル・ウィンドウ枠固定は見本と同じになる。

**`totaltest.xlsx` が必要。** 削除すると生成できなくなる。
