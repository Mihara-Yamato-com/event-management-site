# 試験データ

結合試験（T4-4 / T5-1）とデモの実演で使う**入力用ファイル**の置き場。

---

## これは成果物ではない

**納品する成果物は `index.html` 1ファイルのみ**（CLAUDE.md §1 制約2）。
本ディレクトリのファイルは、**試験者がファイル選択ダイアログから手で選ぶための素材**であり、
`index.html` から参照されることはない。

| 制約 | 抵触しない理由 |
|---|---|
| 制約2 ファイル分割の禁止 | `index.html` はこれらを読み込まない。成果物は単一ファイルのまま |
| 制約7 外部画像URLの参照禁止 | `<img src>` や CSS の `url()` で参照しない。`<input type="file">` から読み込み、**Blob として IndexedDB に格納される** |

つまり画像は「アプリの一部」ではなく「**利用者がアップロードするファイル**」の位置づけになる。

---

## 画像/ に置くもの

アップロードを伴う入力は3つある。仕様は `仕様決定シート.md` を参照。

| 用途 | ID | 制約 | 推奨サイズ |
|---|---|---|---|
| イベントのカバー画像 | D-15 | png / jpeg / webp、2MB以下、保存時に長辺1200pxへ縮小 | 1200×400（横長バナー） |
| 組織ロゴ | D-37 | 同上、保存時に長辺256pxへ縮小 | 256×256（正方形） |
| ヘッダー画像 | D-38 | 同上、保存時に長辺1200pxへ縮小 | 1200×400（横長バナー） |

### 試験で必要になる素材

`仕様決定シート.md`「試験書へ流用する項目」に対応するもの。

| 素材 | 確認する項目 |
|---|---|
| 2MB以内の大きい画像（長辺1200px超） | 長辺1200pxに縮小されて保存される |
| **2MB超**の画像 | 「画像は2MB以内のファイルを選択してください」でエラーになる |
| **正方形**の画像 | 公開ページのヘッダー（横長）と一覧カード（16:9）の両方で崩れず表示される |
| 対応外の拡張子（例: `.gif` / `.bmp`） | 受け付けない |

---

## 資料（S-16 / F-34）で使うファイル

資料の登録は画像に限らない。`pdf` / `png` / `jpg` / `jpeg` / `xlsx` / `docx`、1ファイル5MB以下、20件まで（D-40）。
**5MB超のファイル**と**対応外の拡張子**も、異常系の確認用に用意しておく。

---

## 注意

- **リポジトリに大きなファイルを置きすぎない。** 試験に要るものだけに絞る
- 実在の個人が写った写真は使わない。試験用の素材か、自社で権利を持つものにする

## 収録ファイル

### 画像/ — 受領した写真（1200px JPEG に変換済み）

元の PNG は 1536×1024 で **4枚が2MBを超えており、アプリに拒否される**。
長辺1200pxの JPEG に変換したものを `.jpg` として併置してある。**デモには `.jpg` を使う。**

| ファイル | サイズ | 判定 |
|---|---|---|
| `セミナー１.jpg` | 121 KB | ✓ 2MB以内 |
| `セミナー２.jpg` | 134 KB | ✓ 2MB以内 |
| `勉強会１.jpg` | 109 KB | ✓ 2MB以内 |
| `勉強会２.jpg` | 127 KB | ✓ 2MB以内 |
| `説明会.jpg` | 138 KB | ✓ 2MB以内 |

元の `.png` は参考として残してある（合計約11MB）。不要なら削除してよい。

### 画像/生成/ — 生成した画像

デモ用。カテゴリ別のバナーは、そのままイベントのカバー画像に使える。

| ファイル | 用途 |
|---|---|
| `バナー_{カテゴリ}_1200x400.jpg`（6枚） | イベントのカバー画像（D-15）。推奨サイズちょうど |
| `ロゴ_ACTIO_256x256.png` | 組織ロゴ（D-37）。正方形・推奨サイズちょうど |
| `組織ヘッダー_1200x400.jpg` | 組織のヘッダー画像（D-38） |

試験用。異常系・境界値の確認に使う。

| ファイル | 確認する項目 | 期待結果 |
|---|---|---|
| `試験_大きい_2400x1600.jpg` | 長辺1200px超のリサイズ | 長辺1200pxに縮小されて保存される |
| `試験_正方形_800x800.jpg` | 正方形をカバー画像にした場合 | 公開ページのヘッダーと一覧カードの両方で崩れない |
| `試験_縦長_400x1600.jpg` | 極端な縦横比 | 中央トリミングで枠に収まる |
| `試験_2MB超_900x900.png` | 2MBの上限（D-15 / D-37 / D-38） | 「画像は2MB以内のファイルを選択してください」 |
| `試験_対応外形式.gif` | 対応外の画像形式 | 受け付けない |

### 資料/ — S-16 資料の登録用

| ファイル | 確認する項目 | 期待結果 |
|---|---|---|
| `進行台本_サンプル.pdf` | 正常系の登録・ダウンロード | 登録でき、原本のまま開ける |

## 生成方法

Pillow や ImageMagick は使わず、**headless Chrome の canvas** で生成・変換した。
再生成が必要になった場合も同じ方法で作れる（画像処理ライブラリの導入は不要）。
`試験_2MB超_900x900.png` だけは、圧縮が効かないランダムノイズを Python の `zlib` で無圧縮 PNG にして作っている。
