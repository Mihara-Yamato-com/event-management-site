## 0. 共通ルール

| 項目 | 内容 |
|---|---|
| 開き方 | `index.html` を**ダブルクリックして `file://` で開く**。ローカルサーバは使わない |
| ブラウザ | Chrome。ウィンドウは**最大化**したまま最後まで変えない |
| 撮り方 | `Win` + `PrintScreen`（画面全体が `ピクチャ\Screenshots` に自動保存される） |
| 保存先 | `C:\Users\022611\Pictures\Screenshots`（触らなくてよい。あとでこちらがリネームする） |
| 順番 | **下の撮影No.の順に撮る。** 順番がファイル名の決定に使われるため、飛ばしたら申告する |
| エラーの写し方 | エラーメッセージが**画面に出ている状態**で撮る。トーストは消える前に撮る |
| ダイアログの写し方 | `confirm()` のダイアログは**表示されたまま**撮る（OK/キャンセルを押す前） |

**撮影者がやること**: 順番どおりに撮るだけ。ファイル名は付けなくてよい。
**撮り終わったら**: 「撮り終わった」と伝える。撮影No.順にリネームして `試験エビデンス/` へ移動する。

## フェーズ7 旧データからの読み込み（10-04／2枚）

**この項目だけは通常の操作では再現できない。** 旧スキーマ（バージョン1・`files` ストアなし）の
データを作ってから、今の `index.html` で開く必要がある。

1. `index.html` を開いた状態で `F12` → **Console** タブ
2. 次を貼り付けて実行する（旧バージョン相当のデータを作る）

```js
// 旧スキーマ(v1)のDBを作り、イベント1件と申込1件を入れる
indexedDB.deleteDatabase('event-manager-db').onsuccess = function () {
  var req = indexedDB.open('event-manager-db', 1);
  req.onupgradeneeded = function (e) {
    var db = e.target.result;
    db.createObjectStore('events', { keyPath: 'id' });
    db.createObjectStore('entries', { keyPath: 'id' });
    db.createObjectStore('settings', { keyPath: 'key' });
  };
  req.onsuccess = function (e) {
    var db = e.target.result;
    var tx = db.transaction(['events', 'entries', 'settings'], 'readwrite');
    tx.objectStore('events').put({
      id: 'ev-old-1', title: '旧バージョンで作ったイベント', status: 'published',
      category: '勉強会', capacity: 30, ticketTypes: [{ id: 'tt-old-1', name: '一般', capacity: 30 }],
      startAt: '2026-08-20T19:00', endAt: '2026-08-20T20:30', venue: '本社 3F セミナールーム',
      description: '旧データからの読み込み確認用', createdAt: '2026-07-01T10:00'
    });
    tx.objectStore('entries').put({
      id: 'en-old-1', eventId: 'ev-old-1', ticketTypeId: 'tt-old-1',
      name: '旧データ 太郎', email: 'old@example.com', code: 'OLD00001',
      status: 'confirmed', checkedIn: false, createdAt: '2026-07-02T10:00'
    });
    tx.objectStore('settings').put({ key: 'passcode', value: 'test1234' });
    tx.oncomplete = function () { console.log('旧スキーマ(v1)を作成しました'); };
  };
};
```

3. `F12` → **Application** タブ → **IndexedDB** → `event-manager-db` を開く
